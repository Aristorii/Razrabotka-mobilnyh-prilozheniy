## Задание 1 

**Задача:**

```text
Объявите: имя (String)
возраст (Int)
рост в метрах (Double)
активен ли аккаунт (Boolean)
```

**Выведите карточку:**
```text
Имя: Анна
Возраст: 25 лет
Рост: 1.75 
Активен: true
```
## Решение:

```python
fun main()
{
    val name = "Анна"
    val age = 25
    val height = 1.75
    val active = true

    println("Имя: $name")
    println("Возраст: $age лет")
    println("Рост: $height м")
    println("Активен: $active")
}
```

## Задание 2 

```text
Прочитайте ширину и высоту
выведите площадь и периметр с двумя знаками после запятой
```
## Решение:

```python
fun main()
 {
    print("Ширина: ")
    val w = readln().toDouble()
    print("Высота: ")
    val h = readln().toDouble()

    val area = w * h
    val perimeter = 2 * (w + h)
    println("Площадь: %.2f".format(area))
    println("Периметр: %.2f".format(perimeter))
}
```

## Задание 3

```text
Введите температуру в °C
выведите в °F по формуле F = C * 9/5 + 32
Используйте целочисленное деление аккуратно.
```
## Решение:

```python
fun main()
{
    print("Градусы Цельсия: ")
    val c = readln().toDouble()
    val f = c * 9.0 / 5.0 + 32.0
    println("%.1f °C = %.1f °F".format(c, f))
}
```

## Задание 4

```text
Спросить возраст
вывести «Вы совершеннолетний»
 / «Ещё нет» /
«Некорректный ввод»
```
## Решение:

```python
fun main()
{
    print("Ваш возраст: ")
    val age = readln().toIntOrNull()

    if (age == null) {
        println("Некорректный ввод")
    } else if (age >= 18) {
        println("Вы совершеннолетний")
    } else {
        println("Ещё нет")
    }
}
```

## Задание 5

```text
Пользователь вводит числа через пробел
Выведите их сумму и среднее.
```
## Решение:

```python
fun main()
{
    print("Введите числа через пробел: ")

    val nums = readln().trim().split(" ").mapNotNull { it.toDoubleOrNull() }

    val sum = nums.sum()
    val avg = sum / nums.size

    println("Сумма: $sum")
    println("Среднее: %.2f".format(avg))
}
```

## Задание 6

```text
Даны название товара и цена.
Выведите чек шириной 30 символов с точками
между названием и ценой.
```
## Решение:

```python
fun main()
{
    print("Товар: ")
    val name = readln()
    print("Цена: ")

    val price = readln().toDouble()
    val formattedPrice = "%.2f".format(price)

    val dotsCount = 30 - name.length - formattedPrice.length
    val dots = ".".repeat(dotsCount)

    val receipt = """
        $name$dots$formattedPrice
    """.trimIndent()

    println(receipt)
}
```

## Задание 7

```text
Пользователь вводит сумму в рублях и курс доллара (сколько рублей за 1 $).
Программа считает сумму в долларах, удерживает фиксированную комиссию 1.5 %
выводит результат с двумя знаками после запятой. Некорректный ввод — понятное сообщение, без падения.
```
## Решение:

```python
fun main()
{
    print("Сумма в рублях: ")
    val rub = readln().toDoubleOrNull()

    print("Курс (руб. за 1 $): ")
    val rate = readln().toDoubleOrNull()

    if (rub == null || rate == null) {
        println("Ошибка: введите числа.")
    }
else
{
        val commission = rub * 0.015
        val resultRub = rub - commission
        val resultUsd = resultRub / rate

        println("Сумма:       %.2f ₽".format(rub))
        println("Комиссия:    %.2f ₽ (1.5 %%)".format(commission))
        println("К получению: %.2f ₽".format(resultRub))
        println("В долларах:  %.2f $".format(resultUsd))
 }
}
```
